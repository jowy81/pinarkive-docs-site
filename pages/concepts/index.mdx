# Concepts

PinArkive runs IPFS content across **clusters** (regional pinning and storage), serves it through **gateways**, and exposes separate **production** and **sandbox** API hosts for integration vs demos.

## Topics

- **[Gateways](/concepts/gateways)** — How to serve pinned CIDs over HTTPS (global and regional hosts).
- **[Clusters](/concepts/clusters)** — Multi-cluster pinning, the `cl` parameter, and allowed clusters per plan.
- **[Environments](/concepts/environments)** — Production API vs DEV sandbox for docs and playgrounds.
- **[Timelocks](/concepts/timelocks)** — Optional expiration on pins (premium plans).
