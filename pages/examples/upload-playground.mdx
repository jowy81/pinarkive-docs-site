# Upload demo

The **Upload demo** (`sample1.pinarkive.com`) lets you upload files through a simple UI. It uses the [DEV sandbox](/concepts/environments) (not production).

## Try it

**[Open Upload demo →](https://sample1.pinarkive.com)**

## What it does

- Drag and drop one or more files (demo size cap)
- Upload via a server-side proxy to `https://api-dev.pinarkive.com`
- Display CID and gateway link for each file in **your browser session**
- Fixed **48-hour timelock** on uploads and pins (files expire automatically)
- Copy link or open in a new tab

## Use case

Reference for building your own upload UI (Next.js or React): get file → `POST /files` → show CID and gateway URL.
