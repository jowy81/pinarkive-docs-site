# API Playground

The **API Playground** (`playground.pinarkive.com`) lets you run PinArkive API v3 operations from the browser. Requests go through a server-side proxy to **`https://api-dev.pinarkive.com`** with a dedicated demo API key ([sandbox](/concepts/environments)).

## Try it

**[Open API Playground →](https://playground.pinarkive.com)**

## What it does

- Upload, pin, list, and delete via `/api/*` routes on the playground host
- **List files** returns only items uploaded in your session
- Code snippets for curl, JavaScript, Python, and other SDKs (examples use the DEV API base)
- Rate limited per IP for fair use
