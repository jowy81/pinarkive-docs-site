# Secure Share

The **Secure Share** demo (`sample2.pinarkive.com`) encrypts files in the browser before upload. Only someone with the password can decrypt. Uploads use the [DEV sandbox](/concepts/environments).

## Try it

**[Open Secure Share →](https://sample2.pinarkive.com)**

## What it does

- Encrypt with **AES-256-GCM**; key derived via **PBKDF2** (SHA-256, 250k iterations)
- Password never sent to PinArkive servers
- Upload encrypted payload to IPFS via the demo proxy
- Share link + password out of band
